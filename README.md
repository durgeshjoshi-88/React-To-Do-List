A simple, responsive, and user-friendly To-Do List Application built using React.js.
This app allows users to add, delete, and manage daily tasks effortlessly.

🚀 Live Demo

The application is deployed on Netlify.
👉 Live Link: `reactapp-to-do-list.netlify.app`

📌 Features
  ➕ Add new tasks
  🗑️ Delete tasks
  ✔️ Mark tasks as completed
  📱 Fully responsive UI
  ⚡ Fast and lightweight

🛠️ Tech Stack
React.js 
JavaScript (ES6+)
CSS / Tailwind / Styled Components (depending on what you used)
